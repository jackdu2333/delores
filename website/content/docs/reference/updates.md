---
title: Updates
description: Not in the current app.
---

Updates is not part of the current app. The source is parked under Packs/LegacyFeatures/ and does not appear in Settings, the launcher, or the menu bar.

There is no in-app updater and no Check for Updates command. Install a new build from GitHub Releases. A Homebrew cask for this app must not set auto_updates true, so brew upgrade can replace it.
